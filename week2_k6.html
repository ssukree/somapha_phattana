ตัวชี้ตำแหน่ง รายการ และข้อความ

สื่อการสอนวิทยาการคำนวณระดับชั้นประถมศึกษาปีที่ 6 เพื่อฝึกการอ่านและการแก้ไขข้อมูลตามตำแหน่ง

1. รู้จักตัวชี้ตำแหน่ง 2. การแก้ค่าในรายการ 3. ข้อความแก้ไม่ได้ 4. สรุปความแตกต่าง 5. เกมฝึกทักษะ
บทที่ 1

รู้จักตัวชี้ตำแหน่ง (Index) และรายการ (List)

ในการเขียนโปรแกรมด้วยภาษาไพทอน (Python) เรามักเก็บข้อมูลหลายชิ้นไว้ด้วยกันในกล่องเรียงแถวที่เรียกว่า รายการ โดยใช้เครื่องหมายก้ามปู [...] ครอบข้อมูลไว้

เปรียบเทียบให้เห็นภาพ ลองจินตนาการว่ามีตู้ล็อกเกอร์วางเรียงกัน 4 ช่อง โดยแต่ละช่องมีหมายเลขป้ายติดอยู่ข้างหน้า เราเรียกป้ายหมายเลขช่องนี้ว่า ตัวชี้ตำแหน่ง ซึ่งในภาษาคอมพิวเตอร์จะเริ่มนับช่องแรกจากเลข 0 เสมอ ไม่ใช่เลข 1
ทดลองคลิกกล่องผลไม้ด้านล่าง เพื่อดูการแสดงค่าตามตัวชี้ตำแหน่ง
ช่วงลองเล่น ลองดู นำโค้ดไปทดสอบในสมุดบันทึกกูเกิลโคแล็บ (Google Colab)
เปิดโคแล็บ 
fruits = ["แอปเปิล", "กล้วย", "ส้ม", "แตงโม"]
print("ตำแหน่งที่ 0 คือ", fruits[0])
print("ตำแหน่งที่ 2 คือ", fruits[2])
คำแนะนำ ลองเปลี่ยนตัวเลขในวงเล็บก้ามปูจาก 2 เป็น 1 หรือ 3 แล้วกดปุ่มรันเพื่อสังเกตผลลัพธ์
บทที่ 2

การแสดงค่าและการแก้ไขค่าในรายการ

จุดเด่นของรายการคือเราสามารถเปิดดูข้อมูลช่องใดก็ได้ และยังสามารถนำข้อมูลใหม่เข้าไปแทนที่ข้อมูลเดิมในช่องที่ต้องการได้ ข้อมูลประเภทนี้จึงเรียกว่าข้อมูลที่แก้ไขได้

วิธีการแก้ไขคือระบุชื่อรายการ ตามด้วยตัวชี้ตำแหน่งในเครื่องหมายก้ามปู แล้วใช้เครื่องหมายเท่ากับเพื่อกำหนดค่าใหม่

ทดลองเปลี่ยนผลไม้ในรายการด้วยตนเอง
ช่วงลองเล่น ลองดู ทดลองแก้ไขรายการในโคแล็บ
fruits = ["แอปเปิล", "กล้วย", "ส้ม", "แตงโม"]
print("ก่อนแก้ไข", fruits)

fruits[1] = "มะม่วง"
print("หลังแก้ไข", fruits)
คำแนะนำ ลองเปลี่ยนตำแหน่งที่แก้ไขเป็น 0 หรือ 3 ด้วยชื่อผลไม้อื่นตามต้องการ
บทที่ 3

ข้อความ (String) อ่านได้ แต่แก้ทีละตัวไม่ได้

ข้อมูลอีกชนิดหนึ่งที่พบบ่อยคือ ข้อความ ซึ่งเขียนอยู่ในเครื่องหมายคำพูด เช่น "PYTHON" ข้อความมีตัวชี้ตำแหน่งเริ่มจาก 0 เหมือนกับรายการ เราจึงสามารถเลือกแสดงตัวอักษรทีละตัวได้

ข้อควรระวัง ข้อความเปรียบเหมือนคำที่สลักลงบนป้ายหินแล้ว เราสามารถชี้ดูตัวอักษรแต่ละตัวได้ แต่ ไม่สามารถแก้ไขตัวอักษรเพียงตัวเดียวข้างในได้ หากฝืนสั่งแก้ไข โปรแกรมจะแจ้งข้อผิดพลาดชนิดข้อมูล (TypeError) ทันที
ทดลองคลิกตัวอักษรเพื่ออ่านค่า และทดลองสั่งแก้ไขข้อความ
ช่วงลองเล่น ลองดู ทดสอบอ่านและลองแก้ไขข้อความในโคแล็บ
word = "PYTHON"
print("ตัวอักษรตำแหน่ง 0 คือ", word[0])
print("ตัวอักษรตำแหน่ง 3 คือ", word[3])

# ลองลบเครื่องหมาย # ด้านล่างออกแล้วรันเพื่อดูข้อผิดพลาด
# word[0] = "J"
คำแนะนำ เมื่อรันครั้งแรกจะได้ผลลัพธ์ปกติ จากนั้นให้นักเรียนลบเครื่องหมาย # หน้าบรรทัดสุดท้ายออกแล้วรันอีกครั้งเพื่อดูการแจ้งเตือนของระบบ
