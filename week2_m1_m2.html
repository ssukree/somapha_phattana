ตัวชี้ตำแหน่ง รายการ ข้อความ เงื่อนไข และการวนซ้ำ

สื่อการสอนวิทยาการคำนวณระดับชั้นมัธยมศึกษาปีที่ 1 และ 2 สำหรับคาบเรียน 2 ชั่วโมง

1. ตัวชี้ตำแหน่งบวกและลบ 2. รายการกับเงื่อนไข 3. ข้อความแก้ไม่ได้ 4. วนซ้ำผ่านตัวชี้ตำแหน่ง 5. เกมภารกิจตรรกะ
ชั่วโมงที่ 1 บทที่ 1

ตัวชี้ตำแหน่ง (Index) แบบบวกและแบบลบ

ในภาษาไพทอน (Python) การเข้าถึงข้อมูลภายในรายการ (List) สามารถระบุตำแหน่งได้สองทิศทาง คือ ตัวชี้ตำแหน่งบวก ซึ่งนับจากซ้ายไปขวาโดยเริ่มที่ 0 และ ตัวชี้ตำแหน่งลบ ซึ่งนับจากขวาไปซ้ายโดยเริ่มที่ -1 เพื่อความสะดวกในการดึงข้อมูลตัวท้ายสุดโดยไม่ต้องนับจำนวนสมาชิกทั้งหมดก่อน

การอ้างอิงตำแหน่งด้วย len(scores)
คำสั่ง len(scores) ใช้หาจำนวนสมาชิกในรายการ (ในตัวอย่างนี้มี 4 ตัว) จึงสามารถเขียนอ้างอิงตำแหน่งสำคัญได้ดังนี้
1. ตำแหน่งสุดท้าย เขียนได้ทั้ง scores[-1] และ scores[len(scores) - 1] (เท่ากับ scores[3])
2. ตำแหน่งแรก เขียนได้ทั้ง scores[0] และ scores[-len(scores)] (เท่ากับ scores[-4])
ทดลองคลิกกล่องคะแนนหรือปุ่มด้านล่างเพื่อเปรียบเทียบตำแหน่งบวก ลบ และการใช้ len
ช่วงลองเล่น ลองดู ทดสอบตัวชี้ตำแหน่งบวก ลบ และ len ในกูเกิลโคแล็บ (Google Colab)
เปิดโคแล็บ 
scores = [45, 78, 52, 90]
print("ตัวแรกคือ", scores[0])
print("ตัวสุดท้ายคือ", scores[-1])
print("ตัวสุดท้ายด้วย len()-1 คือ", scores[len(scores) - 1])
print("ตัวแรกด้วย -len() คือ", scores[-len(scores)])
คำแนะนำ ลองเพิ่มคะแนนอีก 1 ตัวต่อท้ายรายการ แล้วสังเกตว่า scores[-1] และ scores[len(scores) - 1] ยังคงชี้ไปยังตัวสุดท้ายได้ถูกต้อง
ชั่วโมงที่ 1 บทที่ 2

การใช้รายการร่วมกับเงื่อนไข if และ else

เมื่อนำตัวชี้ตำแหน่งมาใช้ร่วมกับคำสั่งเงื่อนไขจากสัปดาห์ที่ผ่านมา เราสามารถตรวจสอบข้อมูลในช่องที่ระบุแล้วตัดสินใจแก้ไขค่าได้ทันที เนื่องจากรายการเป็นข้อมูลที่อนุญาตให้แก้ไขค่าทีละตำแหน่ง

จำลองการตรวจสอบคะแนนรายช่องด้วยเงื่อนไข if และ else
ช่วงลองเล่น ลองดู เขียนเงื่อนไขแก้ไขรายการในโคแล็บ
scores = [42, 75, 48, 88]
pos = 0

if scores[pos] < 50:
    scores[pos] = 50
    print("ปรับคะแนนตำแหน่ง", pos, "เรียบร้อย")
else:
    print("ตำแหน่ง", pos, "ผ่านเกณฑ์แล้ว")

print("รายการล่าสุด", scores)
คำแนะนำ ลองเปลี่ยนค่าตัวแปร pos เป็น 1 และ 2 แล้วรันซ้ำเพื่อดูการทำงานของเงื่อนไข
ชั่วโมงที่ 1 บทที่ 3

ข้อความ (String) ตรวจสอบด้วยเงื่อนไขได้ แต่แก้ไขทีละตัวไม่ได้

เราสามารถใช้ตัวชี้ตำแหน่งอ่านตัวอักษรในข้อความเพื่อตรวจสอบเงื่อนไขได้ เช่น การตรวจตัวอักษรตัวแรกของรหัสสินค้า แต่ข้อความไม่สามารถแก้ไขตัวอักษรเฉพาะตำแหน่งได้ หากสั่งแก้จะเกิดข้อผิดพลาดชนิดข้อมูล (TypeError)

แนวทางแก้ปัญหาสำหรับข้อความ หากต้องการเปลี่ยนตัวอักษรบางส่วนในข้อความ ต้องใช้วิธีสร้างข้อความใหม่ขึ้นมาแทน เช่น การนำตัวอักษรใหม่มาต่อเข้ากับส่วนที่เหลือของข้อความเดิมด้วยคำสั่ง "B" + code[1:] โดย code[1:] หมายถึงการตัดเอาข้อความตั้งแต่ตำแหน่งที่ 1 ไปจนจบ
ทดลองตรวจรหัส "A2026" และเปรียบเทียบการแก้ไขแบบผิดวิธีกับวิธีสร้างข้อความใหม่
ช่วงลองเล่น ลองดู ทดสอบข้อความและวิธีสร้างรหัสใหม่ในโคแล็บ
code = "A2026"
if code[0] == "A":
    print("รหัสอยู่ในกลุ่ม A")

# ลองลบเครื่องหมาย # ด้านล่างออกเพื่อสังเกตข้อผิดพลาด
# code[0] = "B"

new_code = "B" + code[1:]
print("รหัสใหม่คือ", new_code)
คำแนะนำ ทดลองรันโค้ดชุดนี้ จากนั้นลบเครื่องหมาย # หน้าบรรทัด code[0] = "B" เพื่อดูการแจ้งเตือนของระบบ
ชั่วโมงที่ 2 บทที่ 4

การวนซ้ำผ่านตัวชี้ตำแหน่งด้วยคำสั่ง for ร่วมกับ range และ len

ในบทที่ 2 หากรายการมีคะแนนสอบจำนวนมาก การเขียนคำสั่ง if scores[0] < 50 ไล่ทีละบรรทัดย่อมทำได้ช้าและซ้ำซ้อน เราจึงใช้คำสั่งวนซ้ำ (Loop) เพื่อสร้างลำดับตัวชี้ตำแหน่งอัตโนมัติ

หลักการทำงานของ for i in range(len(scores))
1. len(scores) ทำหน้าที่นับจำนวนสมาชิกในรายการ เช่น รายการมี 4 ตัว จะได้ค่า 4
2. range(4) ทำหน้าที่สร้างลำดับตัวเลขตัวชี้ตำแหน่งตั้งแต่ 0 1 2 จนถึง 3
3. ตัวแปร i จะรับตัวชี้ตำแหน่งทีละรอบ เพื่อนำไปใช้ตรวจสอบและแก้ไขค่าใน scores[i]
จำลองการทำงานของคำสั่งวนซ้ำทีละรอบ
ช่วงลองเล่น ลองดู ทดลองวนซ้ำปรับคะแนนทั้งรายการในโคแล็บ
scores = [42, 75, 48, 88, 35]

for i in range(len(scores)):
    if scores[i] < 50:
        scores[i] = 50

print("คะแนนหลังปรับทั้งห้อง", scores)
คำแนะนำ ลองเปลี่ยนเกณฑ์จาก 50 เป็น 60 หรือเพิ่มตัวเลขลงในรายการ scores แล้วสังเกตว่าโปรแกรมยังคงทำงานได้ครบทุกตัวโดยไม่ต้องแก้คำสั่งวนซ้ำ

เกมภารกิจตรรกะตัวชี้ตำแหน่ง

ตอบคำถามเชิงวิเคราะห์จำนวน 8 ข้อ ซึ่งรวมเนื้อหาตัวชี้ตำแหน่งบวกและลบ เงื่อนไข ข้อความ และการวนซ้ำ

ข้อที่ 1 จาก 8 คะแนน 0 ตอบถูกต่อเนื่อง 0
